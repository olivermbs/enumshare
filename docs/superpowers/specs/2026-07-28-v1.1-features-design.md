# Enumshare v1.1 Features — Design

Date: 2026-07-28
Status: Approved

Five additive features for the next minor release (v1.1.0). No breaking changes; all
existing commands and generated output remain valid.

## 1. `--check` flag (CI drift detection)

`php artisan enums:export --check` computes the full manifest and generated content but
writes nothing to disk.

Behavior:

- Every enum in the manifest is classified as **up-to-date** (file exists, xxh3 hash of
  content matches), **stale** (file exists, content differs), or **missing** (no file at
  the target path). Reuses the existing hash comparison in `EnumExporter::shouldSkipFile`.
- **Orphans** (see section 3) are detected and reported as warnings, listing what
  `--prune` would delete. `--check` never deletes.
- When the index is enabled (via `--index` or the `index` config key, section 5), the
  `index.ts` file is checked the same way (up-to-date / stale / missing).
- Exit code: `Command::FAILURE` if any file is stale or missing; `Command::SUCCESS`
  otherwise. Orphans alone do not fail the check.
- Output: one summary line per category with file names for stale/missing/orphaned;
  a single "Everything up to date." success line otherwise.
- Flag interactions: `--check` takes precedence over `--force` and `--prune` (both are
  ignored when `--check` is passed). When combined with `--list`, `--list` takes
  precedence (unchanged behavior).

Implementation: `EnumExporter::export()` gains a `check` option. It returns
`['mode' => 'check', 'upToDate' => [...], 'stale' => [...], 'missing' => [...],
'orphans' => [...], 'path' => ..., 'warnings' => ...]`. The command renders the report
and maps it to the exit code. No filesystem writes happen on the check path (no
directory creation either).

## 2. `#[DontExport]` attribute

A parameterless marker attribute that excludes an enum from export everywhere.

```php
#[Attribute(Attribute::TARGET_CLASS)]
final class DontExport {}
```

Behavior:

- `EnumRegistry::getAllEnums()` filters out any enum whose reflection carries the
  attribute, after merging configured and auto-discovered enums. The attribute wins over
  explicit configuration.
- If a `#[DontExport]` enum is also listed in `config('enumshare.enums')`, the export
  emits a config warning: the enum is named and identified as skipped due to the
  attribute. It is not an error; the export continues.
- Interaction with validation: `#[DontExport]` enums are filtered before validation, so
  they produce no validation errors and do not participate in duplicate-short-name
  detection.

File: `src/Attributes/DontExport.php`.

## 3. `--prune` flag (orphan cleanup)

`php artisan enums:export --prune` deletes generated files whose enums no longer exist.

Behavior:

- Runs after writing. Scans the top level of the export directory only (output is flat;
  no recursion).
- A file is an orphan if and only if: it has a `.ts` extension, its content contains the
  auto-generated marker (`// Auto-generated from` for enum files, or the index marker
  `// Auto-generated. Do not edit.`), and this run did not produce it.
- Files without a marker are never touched, so hand-written files in a shared directory
  are safe. An `index.ts` with the marker is pruned when the index is not being generated
  this run.
- Each deleted file is reported by name, plus a summary count. Zero orphans produces no
  output beyond the normal export summary.
- `--check` reports the same orphan set as warnings without deleting (section 1).

Implementation: orphan detection lives in `EnumExporter` (shared between the check and
prune paths); it compares the directory listing against the set of file paths this run
generated or skipped-as-unchanged.

## 4. `AboutCommand` integration

`php artisan about` gains an "Enumshare" section registered in
`EnumshareServiceProvider::boot()` (console branch only), showing:

- **Mode** — `full` or `minimal`
- **Path** — export path, relative to `base_path()` when inside it
- **Auto-discovery** — `Enabled (app/Enums, ...)` or `Disabled`
- **Enums** — total count of exportable enums (configured + discovered, after
  `#[DontExport]` filtering and validity checks)

The count uses class lists only — no label/meta extraction runs. `EnumRegistry` exposes
a public method returning the filtered, validated class list so About and `manifest()`
share one code path. The closure passed to `AboutCommand::add()` resolves the registry
lazily so `about` stays free of side effects and cost when the section is not rendered.

## 5. `index` config option

New config key:

```php
'index' => false,
```

- When `true`, every export generates the barrel `index.ts`, and `--check` includes it.
- The `--index` flag remains as a per-run override to force index generation when the
  config is `false`. There is no flag to disable a config-enabled index (accepted
  limitation, documented in README).
- Effective value: `$options['index'] || config('enumshare.index', false)`.

## Testing

Pest feature tests per feature, following existing test conventions:

- `--check`: exit 0 when clean; exit 1 for stale content and for missing files; nothing
  written or deleted in either case; index included when enabled; orphans reported but
  non-failing.
- `#[DontExport]`: excluded via auto-discovery; excluded when explicitly configured
  (warning emitted); absent from `--list` output; no duplicate-name collision triggered
  by an excluded enum.
- `--prune`: deletes marker-bearing orphans; never deletes files without the marker;
  never deletes files from the current manifest; prunes a stale marker-bearing
  `index.ts`; reports deleted names.
- About: section registered and values correct (testable via `artisan about --json`).
- `index` config: barrel generated without the flag when config is `true`; flag still
  works when config is `false`.
- Existing tsc regression tests continue to pass unchanged (these features do not alter
  generated enum file content).

## Documentation

README updates: `--check` and `--prune` in the Commands section with a short CI example,
`#[DontExport]` row in the Attributes table, `index` key in the Configuration block, and
a one-line mention of `php artisan about`. Config stub (`config/enumshare.php`) gains the
`index` key with a doc block.

## Release

Ship as v1.1.0 with a CHANGELOG entry (features above, plus the v1.0.1-pending bug fixes
if not already released separately).
